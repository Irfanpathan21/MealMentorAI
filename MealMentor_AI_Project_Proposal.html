Abstract

MealMentor AI is a proposed intelligent Android application that leverages artificial intelligence and cloud computing to serve as a personal diet coach. The application will enable users to photograph their meals, automatically identify the food items using computer vision (Azure OpenAI GPT-4o Vision), extract detailed nutritional information, and maintain a comprehensive daily food log.

The core differentiator of MealMentor AI is its AI Dietitian module — a context-aware conversational assistant that behaves like a professional dietitian. It will consider the user’s complete health profile (age, weight, medical conditions, dietary preferences, allergies), parsed health reports (blood work, cholesterol levels), and the specific foods consumed on that day to provide highly personalized meal recommendations.

The application will feature interactive data visualization through detailed charts — calorie trend lines, macronutrient donut charts, weekly progress bar graphs, and nutrient radar charts. The complete system will be built on Microsoft Azure cloud services (App Service, PostgreSQL, Blob Storage, OpenAI Service), ensuring scalability, reliability, and enterprise-grade security.

Keywords: Artificial Intelligence, Nutrition Analysis, Computer Vision, Natural Language Processing, Diet Recommendation, Android Application, Azure Cloud Services, Health Informatics

Chapter 1
Introduction

1.1 Background

The global burden of diet-related diseases has reached unprecedented levels. According to the World Health Organization (WHO), unhealthy diets are among the top risk factors for non-communicable diseases (NCDs), which collectively account for approximately 71% of all deaths globally. In India, the National Family Health Survey (NFHS-5, 2019–2021) reports that 24% of adults are overweight or obese, while 18.7% of women and 16.2% of men are underweight — highlighting a dual burden of malnutrition.

Despite growing health consciousness in the post-COVID era, traditional methods of dietary tracking remain highly challenging. Manual food logging — manually searching databases, reading nutritional labels, or maintaining food diaries — is tedious, error-prone, and unsustainable. Research published in the Journal of Medical Internet Research indicates that manual food logging has an abandonment rate exceeding 60% within the first two weeks due to logging fatigue. Furthermore, generic calorie-tracking apps fail to provide personalized recommendations that account for individual medical conditions, blood work results, or daily dietary context.

Recent advancements in Artificial Intelligence, particularly in computer vision and Large Language Models (LLMs), present transformative opportunities to address these issues. Vision-capable models such as GPT-4o can now identify food items from photographs with remarkable accuracy, while conversational AI can provide personalized dietary guidance that was previously accessible only through expensive professional consultations. MealMentor AI is conceived at this intersection — an intelligent Android application combining AI-powered food recognition, automated nutritional analysis, comprehensive meal tracking, interactive data visualization, and a conversational AI dietitian.

1.2 Objectives

  1. To design and develop an Android application that uses AI-powered computer vision (Azure OpenAI GPT-4o) to identify food items from photographs and extract detailed nutritional information.
  2. To implement a comprehensive daily meal tracking system with persistent food logging and progress monitoring against personalized targets.
  3. To build an AI Dietitian chat module — a context-aware conversational assistant providing personalized meal recommendations based on health profile, medical conditions, and daily food intake.
  4. To create interactive data visualizations (line charts, donut charts, bar graphs, radar charts) presenting nutritional trends over daily, weekly, and monthly periods.
  5. To implement health report analysis that allows users to upload medical reports for AI-based parsing, integrating extracted health markers into dietary recommendations.
  6. To deploy the backend on Microsoft Azure cloud services, demonstrating proficiency in cloud-native application development.

1.3 Purpose, Scope, and Applicability

1.3.1 Purpose

The primary purpose of MealMentor AI is to bridge the accessibility gap in personalized nutrition guidance. Professional dietitian consultations cost ₹500–₹2,000 per session in India, making them financially inaccessible to a significant portion of the population. By providing a 24/7 AI-powered dietitian, MealMentor AI democratizes access to tailored dietary advice. Additionally, it aims to reduce manual logging fatigue through image-based food identification, eliminate inaccurate self-reporting, and connect isolated health data (such as blood work) directly to daily meal choices.

1.3.2 Scope

In Scope:

  • Android mobile application using React Native (Expo)
  • AI-powered food image recognition and nutritional analysis
  • User authentication and health profile management
  • Daily meal logging (AI-assisted and manual entry)
  • Interactive nutritional charts and analytics dashboard
  • Conversational AI Dietitian with context-aware recommendations
  • Health report upload and AI-based parsing
  • Cloud deployment on Microsoft Azure

Out of Scope:

  • iOS application (future extension via React Native cross-platform)
  • Wearable device integration
  • Barcode/QR code scanning for packaged foods
  • Multi-language support (English only in current version)

1.3.3 Applicability

MealMentor AI is highly applicable in various real-world scenarios:

  1. Personal Health Tracking: Individuals seeking to maintain a healthy lifestyle, lose weight, or track macronutrients and micronutrients efficiently.
  2. Chronic Disease Management: Patients managing diet-sensitive conditions such as diabetes, hypertension, obesity, or cardiovascular diseases can align their meals with clinical targets.
  3. Clinical Follow-ups: Healthcare professionals can use the parsed reports and meal history to monitor patients' compliance with dietary recommendations.
  4. Corporate Wellness: Organizations can deploy the platform to improve employee health outcomes by promoting healthy eating habits.

1.4 Achievements

The system aims to achieve several key milestones:

  1. Frictionless Food Logging: Reducing food logging time by over 80% through one-tap image recognition instead of database searching.
  2. High Recognition Accuracy: Achieving at least 85% accuracy in identifying food items and portion sizes from images.
  3. Hyper-Personalized Guidance: Delivering context-aware meal recommendations that dynamically adjust based on user profile, blood reports, and current daily intake.
  4. Scalable Cloud Infrastructure: Establishing a robust, secure, and cost-effective backend architecture using Microsoft Azure services.

Chapter 3
Literature Survey

3.1 Existing Systems

MyFitnessPal (200M+ users) maintains a database of 14+ million food items with manual entry and barcode scanning, but lacks AI-powered food recognition and contextual intelligence.

HealthifyMe is an India-focused platform offering calorie tracking and human dietitian consultations (premium: ₹999–₹4,999/month). Its “Snap” feature uses basic image recognition but lacks a conversational AI dietitian.

Lose It! offers “Snap It” food recognition from photos but supports limited food categories and lacks context-aware recommendations or health report integration.

Yazio is a European calorie counter with barcode scanning and meal planning but no AI-powered food recognition or conversational dietary guidance.

3.2 Research Papers Reviewed

[1] Mezgec & Koroušić Seljak (2017) — “NutriNet” achieved 86.72% top-5 accuracy using CNNs for food recognition across 520 categories. Validates AI-based food recognition viability; MealMentor AI uses more advanced GPT-4o Vision.

[2] Bossard et al. (2014) — Introduced the Food-101 dataset (101,000 images, 101 categories), establishing benchmarks for food recognition models.

[3] Sahoo et al. (2019) — “FoodAI” proposed multi-task learning for simultaneous food recognition, ingredient detection, and nutritional estimation — validating the pipeline approach used in MealMentor AI.

[4] Vaswani et al. (2017) — “Attention Is All You Need” introduced the Transformer architecture, the foundation of GPT-4o and all modern LLMs powering this project.

[5] Achiam et al. (2023) — GPT-4 Technical Report details multimodal (vision) capabilities for understanding images alongside text, directly relevant to MealMentor AI’s food analysis.

Chapter 4
Proposed System

4.1 System Overview

MealMentor AI is a three-tier Android application:

  1. Presentation Tier: React Native (Expo) mobile app with 10+ screens.
  2. Application Tier: Node.js + Express RESTful API deployed on Azure App Service with 15+ endpoints.
  3. Data Tier: Azure PostgreSQL (pgvector), Azure Blob Storage, and Azure OpenAI Service (GPT-4o + ada-002).

4.2 Key Features

#FeatureDescription
1AI Food RecognitionPhotograph meals → GPT-4o Vision identifies food items, estimates portions, extracts calories, macros (protein, carbs, fat), and micronutrients (vitamins, minerals).
2Daily Meal TrackingEvery meal logged with timestamp, meal type, nutritional data, and photo. Dashboard shows real-time progress toward daily targets with circular progress indicators.
3Interactive ChartsCalorie trend line chart, macronutrient donut chart, weekly stacked bar chart, and nutrient radar chart — with daily/weekly/monthly views.
4AI Dietitian ChatConversational AI with access to user’s complete health profile, today’s meals, nutritional gaps, and health reports. Provides personalized meal advice.
5Health Report ParsingUpload blood work/medical reports → AI extracts cholesterol, blood sugar, vitamin levels, thyroid markers → factors into all dietary recommendations.
6Proactive SuggestionsBased on time of day and nutritional gaps, app suggests 3 meals that optimally fill remaining nutritional needs while respecting all health constraints.
7Meal HistorySearchable calendar view of all past meals with complete nutritional data for long-term tracking.

4.3 AI Dietitian — Core Differentiator

The AI Dietitian is the flagship feature that sets MealMentor AI apart. Every AI interaction builds a rich context from:

  1. User profile (age, weight, conditions, preferences, allergies)
  2. Parsed health report data (blood markers, vitamin levels)
  3. Today’s complete meal log with nutritional totals
  4. Calculated remaining nutritional budget (calories, protein, carbs, fat)
  5. Identified nutritional gaps (nutrients below 50% daily value)
  6. 7-day meal history for pattern recognition

Example Interaction:

“I had poha for breakfast and chole chawal for lunch. What should I eat for dinner?”

→ The AI calculates remaining caloric budget (~600 cal), identifies low protein (35g of 80g target), and suggests high-protein dinners respecting the user’s vegetarian preference and lactose intolerance, with specific nutritional breakdowns for each suggestion.

5.2 Key Data Flows

Food Image Analysis Flow

User captures photo → App sends to API → API uploads to Blob Storage → API sends image to GPT-4o Vision → GPT-4o identifies food + nutrition → API stores in PostgreSQL (meals + nutrition_entries tables) → API generates personalized recommendation using user profile context → Results returned to app with charts-ready data

AI Dietitian Chat Flow

User types message → App sends to API → API fetches from DB: - User profile + health conditions + allergies - Today's meals + nutrition totals + remaining budget - Health report markers + recent chat history → API builds context-rich system prompt → Sends to GPT-4o → Response returned to app → Stored in chat history

Expected Outcomes & Future Scope

  2. An operational AI Dietitian providing personalized, context-aware dietary recommendations that simulate professional dietitian consultation quality.
